DocuExtract API

Send a document, get JSON back. No templates. No training. Works in 5 minutes.

DocuExtract converts unstructured documents — invoices, receipts, contracts, resumes, bank statements — into clean, validated JSON using Claude AI. You send a document (image, PDF, or URL), specify what you want extracted, and receive structured data in seconds.

Base URL https://docuextract-azure.vercel.app/v1
FeatureDetail
AuthenticationBearer token (API key)
Request formatJSON (Content-Type: application/json)
Response formatJSON
Max file size10 MB
Supported formatsPDF, PNG, JPG, WEBP (base64 or URL)
Default modelClaude Haiku 4.5 (fast)
Accurate modelClaude Sonnet 4.6 (complex documents)

Quick Start

Extract structured data from a document in 3 steps.

1

Get your API key

Sign up at docuextract-azure.vercel.app to get your free API key. It looks like dex_live_xxxxxxxxxxxxxxxx.

2

Make your first extraction

Send a document URL (or base64) to /v1/extract:

bash 
curl https://docuextract-azure.vercel.app/v1/extract \
  -H "Authorization: Bearer dex_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "document": "https://example.com/invoice.pdf",
    "type": "invoice"
  }'
javascript 
const response = await fetch('https://docuextract-azure.vercel.app/v1/extract', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer dex_live_YOUR_KEY',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    document: 'https://example.com/invoice.pdf',
    type: 'invoice',
  }),
});

const result = await response.json();
console.log(result.data);
// { vendor_name: "Acme Corp", total_amount: 1250.00, ... }
python 
import requests

response = requests.post(
    'https://docuextract-azure.vercel.app/v1/extract',
    headers={
        'Authorization': 'Bearer dex_live_YOUR_KEY',
        'Content-Type': 'application/json',
    },
    json={
        'document': 'https://example.com/invoice.pdf',
        'type': 'invoice',
    }
)

result = response.json()
print(result['data'])
# {'vendor_name': 'Acme Corp', 'total_amount': 1250.0, ...}

Authentication

All API endpoints (except GET /v1/health) require authentication via a Bearer token in the Authorization header.

http
Authorization: Bearer dex_live_xxxxxxxxxxxxxxxxxxxxxxxx

API Key Format

API keys start with dex_live_ followed by 32 random characters. Keys are generated when you sign up and can be regenerated from your dashboard.

Keep your API key secret Never expose your API key in client-side code or public repositories. Use environment variables to store it securely.

Rate Limit Headers

Every authenticated response includes rate limit information:

HeaderDescription
X-RateLimit-Limit-MinuteMaximum requests per minute for your plan
X-RateLimit-Remaining-MinuteRemaining requests this minute
X-RateLimit-Limit-MonthMaximum extractions per month for your plan
X-RateLimit-Remaining-MonthRemaining extractions this month

POST /v1/extract

Extract structured data from a document. This is the core endpoint.

POST https://docuextract-azure.vercel.app/v1/extract

Request Body

FieldTypeRequiredDescription
documentstringYesDocument as base64-encoded string or a publicly accessible URL
typestringNoDocument type hint. One of: invoice, receipt, bank_statement, resume, contract, form, id_document. Auto-detected if omitted.
modelstringNo"fast" (default) or "accurate". Fast uses Claude Haiku; accurate uses Claude Sonnet for complex/multi-page documents.
schemaobjectNoCustom JSON schema describing the fields to extract. When provided, the extraction is guided by your schema.

Examples

bash
# Extract from URL
curl https://docuextract-azure.vercel.app/v1/extract \
  -H "Authorization: Bearer dex_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "document": "https://example.com/receipt.jpg",
    "type": "receipt"
  }'

# Extract from base64 (accurate mode for complex docs)
curl https://docuextract-azure.vercel.app/v1/extract \
  -H "Authorization: Bearer dex_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "document": "data:application/pdf;base64,JVBERi0xLj...",
    "model": "accurate"
  }'
javascript
import fs from 'fs';

// Extract from a local file (base64)
const fileBuffer = fs.readFileSync('invoice.pdf');
const base64 = `data:application/pdf;base64,${fileBuffer.toString('base64')}`;

const res = await fetch('https://docuextract-azure.vercel.app/v1/extract', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.DOCUEXTRACT_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    document: base64,
    type: 'invoice',
  }),
});

const { data, metadata } = await res.json();
console.log(`Extracted ${Object.keys(data).length} fields at ${metadata.confidence * 100}% confidence`);
python

result = resp.json()
print(result['data']['total_amount'])  # 1250.00

POST /v1/detect

Detect the type of a document without extracting its data. Useful when you need to route documents to different processing pipelines.

POST https://docuextract-azure.vercel.app/v1/detect

Request Body

FieldTypeRequiredDescription
documentstringYesDocument as base64-encoded string or a publicly accessible URL
bash
curl https://docuextract-azure.vercel.app/v1/detect \
  -H "Authorization: Bearer dex_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"document": "https://example.com/document.pdf"}'
javascript
const res = await fetch('https://docuextract-azure.vercel.app/v1/detect', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.DOCUEXTRACT_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ document: 'https://example.com/document.pdf' }),
});

const { type, confidence } = await res.json();
// type: "invoice", confidence: 0.98
python
resp = requests.post(
    'https://docuextract-azure.vercel.app/v1/detect',
    headers={'Authorization': f"Bearer {os.environ['DOCUEXTRACT_KEY']}"},

)
print(resp.json())  # {'type': 'invoice', 'confidence': 0.98}

Request Body

FieldTypeRequiredDescription

  -H "Authorization: Bearer dex_live_YOUR_KEY" \

Document Types

DocuExtract automatically detects document types, or you can specify one explicitly. Each type has a specialized extraction prompt tuned for that document's structure.

TypeDescriptionKey Fields Extracted
invoice Vendor invoices and billing statements vendor name, invoice number, dates, line items, totals, payment terms
receipt Purchase receipts from retail, restaurants, etc. merchant name, date, items purchased, subtotal, tax, total, payment method
bank_statement Bank and credit card statements account number, period, opening/closing balance, transactions
resume CVs and resumes name, contact info, work experience, education, skills
contract Legal agreements and contracts parties, effective date, termination date, key obligations, governing law
form Filled forms (applications, surveys, intake forms) all labeled fields and their values
id_document ID cards, passports, driver's licenses name, date of birth, expiry, document number, issuing authority
unknown Fallback for unrecognized types best-effort extraction of all visible structured data

Error Codes

All errors return a JSON response with error and message fields, plus an appropriate HTTP status code.

json
{
  "error": "invalid_api_key",
  "message": "Invalid or missing API key."
}

4xx Client Errors

401 — invalid_api_key
The API key is missing, malformed, or revoked. Check your Authorization header.
400 — invalid_request
A required field is missing or a field value is invalid (e.g., unknown document type).
400 — file_too_large
The document exceeds the 10 MB size limit.
400 — unsupported_format
The file format is not supported. Use PDF, PNG, JPG, or WEBP.
400 — invalid_url
The document URL is not accessible or returned a non-200 status.
429 — rate_limit_exceeded
You've exceeded your per-minute or per-month rate limit. Check the X-RateLimit-* headers. Upgrade your plan for higher limits.
405 — method_not_allowed
The HTTP method used is not allowed for this endpoint.

5xx Server Errors

500 — extraction_failed
The AI extraction failed after retrying. This is rare — try again. If it persists, the document may be corrupted or unreadable.
500 — internal_error
Unexpected server error. Please try again. If it persists, contact support.

Handling Errors

javascript
const res = await fetch('https://docuextract-azure.vercel.app/v1/extract', { /* ... */ });

if (!res.ok) {
  const { error, message } = await res.json();

  if (res.status === 429) {
    // Respect rate limits
    const remaining = res.headers.get('X-RateLimit-Remaining-Month');
    console.error(`Rate limited. Monthly remaining: ${remaining}`);
  } else {
    console.error(`Error ${error}: ${message}`);
  }
  return;
}

const result = await res.json();
python
resp = requests.post('https://docuextract-azure.vercel.app/v1/extract', # ...)

if not resp.ok:
    err = resp.json()
    if resp.status_code == 429:
        print(f"Rate limited: {err['message']}")
    else:
        print(f"Error {err['error']}: {err['message']}")
else:
    result = resp.json()

Overage Pricing

When you exceed your monthly quota, additional extractions are billed at $0.05 per extraction. Overage is metered via Stripe and billed at the end of your billing period. Free plan users are rate-limited at their cap — no overages.
